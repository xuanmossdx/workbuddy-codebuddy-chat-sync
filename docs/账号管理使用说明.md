# 账号管理 · 使用说明

本工具在原有的「聊天记录同步」之外，增加了一个「账号」页，用来查看同一台电脑上 WorkBuddy、Trae、Qoder 的账号与额度。

**它不会签到。** 不发签到/领取请求，不启动调试端口，也不做自动化点击。额度只在手动点「刷新额度」时查询一次。

---

## 1. 两个页签

| 页签 | 作用 |
| --- | --- |
| 聊天记录同步 | 原有功能，把本地历史会话归到指定账号；逻辑、配置格式、日志位置都没有改动 |
| 账号 | 按 WorkBuddy / Trae / Qoder 分区展示账号；WorkBuddy 可新建 / 切换 / 停止，Trae 与 Qoder 只读展示 |

打开窗口默认停在「聊天记录同步」。切到「账号」页才会读取账号列表；这一步只读本地文件，不联网。

---

## 2. 便携目录

程序和数据放在一起：

```
workbuddy-codebuddy-chat-sync.exe
data\
  accounts.json          账号表（昵称、uid、数据目录、登录时间）
  accounts-config.json   客户端路径、账号根目录、超时设置
  account-state.json     最近一次运行状态 / 额度查询缓存
  shortcuts.json         本工具创建的桌面入口（账号 → 快捷方式路径）
  last-sync.json         同步页「上次同步」记录
```

- 优先使用 exe 同级的 `data\`。
- 如果该位置不可写（例如放在 `Program Files` 下且没有权限），自动回退到
  `%APPDATA%\workbuddy-codebuddy-chat-sync\data\`。
- **实际位置显示在「账号」页顶部**，点旁边的「打开」可以直接打开该目录。
- 新建账号的默认根目录是 exe 同级的 `accounts\`；要换位置就改
  `accounts-config.json` 的 `workbuddy.accountsRoot`，或设置环境变量
  `WB_ACCOUNTS_ROOT`。
- Trae 多开实例默认在 exe 同级的 `instances\` 下找（每个子目录的 `appdata\`）。
  实例在别处时，把根目录写进 `accounts-config.json` 的 `trae.instanceRoots`，
  或用环境变量 `WB_CB_TRAE_ROOTS`（多个用 `;` 分隔）。

`data\` 里只放轻量内容。**不复制客户端数据库，不保存登录令牌。**
WorkBuddy 自己的会话数据、账号快照、认证文件仍然在客户端原来的位置。

> 同步工具的 `config.json`、`sync.log` 仍由 `sync_core.py` 管理，位置在
> `%APPDATA%\workbuddy-codebuddy-chat-sync\`，格式与旧版一致。

### 首次运行

如果 `data\accounts.json` 不存在，工具会按空表初始化，并在探测到客户端路径后
写入 `accounts-config.json`。不会从其它目录复制旧数据。

## 3. 账号页

### 产品分区

| 分区 | 展示内容 | 可执行操作 |
| --- | --- | --- |
| WorkBuddy | 本工具登记的实例、昵称、UID、数据目录、运行状态、登录态预计到期、额度 | 新建 WorkBuddy 账号、置前、停止、刷新额度、打开目录 |
| Trae | 默认实例（`%APPDATA%\Trae CN`）与本机其它实例（按 `--user-data-dir` 识别） | 刷新状态、打开目录 |
| Qoder | 单实例（`%APPDATA%\com.qoder.app.stable`） | 刷新额度、打开目录 |

Trae 与 Qoder 由客户端自己管理，本工具只读展示，不切换、不停止、不代为领取。

### 账号卡片

- 第一行：昵称、`默认` / `当前` 标记、UID 前 8 位；右侧是运行状态与登录态。
- 运行状态：绿色「运行中」、灰色「未运行」。
- 登录态：7 天内到期显示琥珀色，已过期显示红色。
- 第二行：该实例的配置目录；Trae 第二实例会标注「设备维度限制」。
- 第三行：额度结果与「刷新额度 / 置前 / 停止 / 桌面入口 / 打开目录」按钮。
  - 蓝色为接口查询结果，附查询时间；
  - 琥珀色「需手动查看」表示查不到，不是故障。
  - 「桌面入口」：已有则在桌面选中该快捷方式；缺失则立即生成。

### 关于额度

| 端 | 来源 | 说明 |
| --- | --- | --- |
| WorkBuddy | 客户端 `auth\*.info` | 令牌是加密信封（`$wbEncrypted`），本工具不读取、不解密、不伪造，通常显示「需手动查看」；令牌恰为明文时只尝试一次只读查询，失败即降级 |
| Trae | `api.trae.cn` 的 `checkin_credits/status` | 只读查询今日领取状态与额度，不发送领取请求。第二实例只展示事实，是否可领以客户端为准 |
| Qoder | `openapi.qoder.sh` 的 `/api/v2/user/plan` | 只读查询套餐信息；查不到时标「需手动查看」 |

**按需查询**：打开页面不会联网，只有点「刷新额度」才查询一次；失败不重试。

## 4. 桌面入口

多账号时，桌面快捷方式是唯一可靠入口。每个 WorkBuddy 账号都应有一个
`WorkBuddy - <昵称>.lnk`，双击即可进入该账号。

- **何时生成**
  - **新建实例一启动就生成临时入口**（`WorkBuddy - 待登录-wb-xx.lnk`），没登完也能双击回来；
  - 登录成功后改成正式昵称入口，并清掉临时登记；
  - 自动登记的默认主账号也会生成；
  - 刷新账号列表时，缺失入口与未登录目录都会自动补建；
  - 卡片上可手动点「桌面入口 / 生成入口」。
- **位置**：系统桌面目录（跟随 OneDrive / 系统重定向）。
- **指向**：该实例目录下的 `launch-workbuddy.ps1`（经 powershell 调用），
  工作目录是该实例目录，图标取 WorkBuddy 客户端图标。不复制客户端，也不复用别的账号路径。
- **登记**：`data\shortcuts.json` 记录 uid → 快捷方式路径；同一账号重复生成只更新原入口。
- **不覆盖其它快捷方式**：桌面已有同名但不是本工具创建的文件时，自动用
  `WorkBuddy - <昵称> (2).lnk`。
- 界面「新建 WorkBuddy 账号」和命令行 `add` 行为一致；失败会明确提示。

### 删除 / 停用账号时

- **停止**只关闭进程，不删除桌面入口；下次双击仍可启动该账号。
- **删除账号**：当前界面没有删除功能。如果手动从 `accounts.json` 移除账号，
  桌面入口**不会自动删除**（避免误删桌面文件），需要手动删除；
  确切路径在 `data\shortcuts.json` 里能查到。
- 换机后旧入口指向的绝对路径失效，建议手动删除旧入口，在新机器上重新新建账号生成。

---

## 5. 换机注意事项

`data\` 里存的是**本机的绝对路径**和**缓存**，不是可移动的客户端数据。

1. **登录态不会跟着走。** 工具不保存令牌，换机后需要在客户端重新登录。
2. **账号目录是绝对路径。** `accounts.json` 里的 `configDir`（如
   `<账号根目录>\workbuddy-accounts\wb-01`）换机后通常不存在。
   此时「打开数据目录」会提示目录不存在，「切换/置前」会失败。
   正确做法：在新机器上用「新建账号」重新建实例并登录；旧记录可以删掉，
   或把 `configDir` 改成新机器上的实际目录。
3. **客户端路径也要更新。** `accounts-config.json` 里的 `exePath`、
   `accountsRoot` 是绝对路径。删掉这两个字段后重启工具，会自动重新探测客户端。
4. **不要把旧机器的客户端 profile 目录拷到 `data\`。** 那属于客户端数据，
   不在本工具的管理范围内，复制过来也不会被识别。
5. 整个文件夹（exe + `data\`）可以一起搬到新机器；如果新位置不可写，
   工具会自动改用 `%APPDATA%`，界面会显示新的实际位置。

## 6. 命令行（可选）

命令行和界面共用同一套数据层，行为与旧版一致：

```powershell
python .\src\wb_accounts.py detect
python .\src\wb_accounts.py add --label 账号-03
python .\src\wb_accounts.py list
python .\src\wb_accounts.py switch wb-01
python .\src\wb_accounts.py stop wb-01
```

`stop` 默认拒绝关闭默认 profile 的主实例，需要加 `--force`。
